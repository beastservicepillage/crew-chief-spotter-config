## About

Crew Chief Spotter Config Manager helps sim racers organize their Crew Chief configurations. Save spotter profiles per sim, manage voice pack selections and document alert thresholds for optimal race pace feedback.

---

## Features

| Feature | Description |
|---------|-------------|
| **Spotter Profiles** | Save Crew Chief configurations per sim and car category |
| **Voice Packs** | Track installed voice packs with language and style notes |
| **Alert Settings** | Document gap, fuel and tyre alert thresholds per profile |
| **Sim Configs** | Organize separate Crew Chief settings per racing simulation |
